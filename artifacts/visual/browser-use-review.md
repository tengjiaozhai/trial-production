## 体验检查清单

### Step 1：填写必填项

- [ ] 项目名称输入框可交互
- [ ] 文件上传流程正常
- [ ] 选择模板下拉框可用

### Step 2：自动获取与冲突

- [ ] Univer sheet 正确显示 PCBA/SKU 数据

### Step 3：补充完善

- [ ] 单元格可编辑

- [ ] 校验结果在侧边栏显示
- [ ] 点击校验卡片后 sheet 聚焦到目标单元格
- [ ] 严重性层级（error/warn/skip/pass）视觉区分

### Step 5：导出预览

- [ ] Sheet 为只读模式
- [ ] 合并/跨列单元格正确显示

- [ ] 流程顺畅，无卡顿
